(`docs/plans/OWNER_REQUIREMENTS_CHECKLIST.md` §4) before store delivery.

the same motif as `BrandBanner`/`WaveProgress` in `components/ui.tsx`.

Required files (referenced by `app.json`):

- `icon.png` — 1024×1024
- `adaptive-icon.png` — 1024×1024 (Android foreground)
- `splash-icon.png` — brand mark on transparent, ~600px
- `favicon.png` — 48×48
